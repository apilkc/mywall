# My research space

https://apilkc.github.io/mywall/

A personal research whiteboard — draggable sticky notes for your dissertation, projects, ideas, blogs, and reading.

## Features

- Free-form board: drag notes anywhere (your layout is remembered)
- Tags you create yourself, plus progress tracking (to-do / in progress / done)
- Search the wall
- Paper styles (blank / grid / lined), 6 colors, and two note sizes
- Light and dark themes
- 30-day trash with restore
- Everything is saved locally in your browser

## Run it

Open `index.html` directly, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then open <http://127.0.0.1:8000>.
